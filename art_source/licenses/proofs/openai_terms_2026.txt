3. Commercial Distribution & Attribution Compliance Summary for Project:
--------------------------------------------------------------------------------
- Commercial Use Allowed      : YES (Full assignment of OpenAI's right, title, and interest in Output; permitted for Steam / commercial game distribution).
- Attribution Required        : NO (attribution_required = N in LICENSES.csv).
- Raw Redistribution Policy   : Raw 1024x1024 / 1024x1536 PNGs are stored only in `art_source/raw/` (Git LFS) for provenance; runtime build ships processed 4-channel RGBA data textures (`assets/art/`) via `process_subject.py` + `export.py`.
- Usage Policies Safeguards   : Project prompts (`tools/art/gen_openai.py` + `art_source/prompts/*.yaml`) strictly prohibit living artists' names, copyrighted third-party IP characters/logos, trademarked symbols, or deceptive watermarking.
- Steam Store AI Disclosure   : Because first-party woodcut subject masters are generated via OpenAI GPT Image API and post-processed into 4-channel data textures, Steamworks Pre-Generated AI Content disclosure should truthfully state that base 2D woodcut silhouettes were assisted by OpenAI Image API under commercial ownership assignment and post-processed via custom channel-packing tools.
